# Downright 1.0.16 release

Downright 1.0.16 is a signed and notarized native Markdown editor and viewer for macOS 14 or newer.

## Release facts

- Quick Look and Finder integration
- Sparkle updates
- `down` and `md` terminal commands
- MIT license
- Download latest signed build: https://github.com/ezzy1630/Downright/releases/latest/download/Downright.dmg

The direct DMG, shell installer, npm launcher, and public Homebrew cask resolve to the same rolling latest artifact. Each verified push to `main` becomes the next Sparkle update.

See the [release evidence](https://downright.cc/known-gaps/) and [GitHub Releases](https://github.com/ezzy1630/Downright/releases).
