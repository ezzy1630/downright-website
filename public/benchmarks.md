# Downright Markdown rendering benchmarks

Downright publishes a baseline rather than a universal speed promise.

- Corpus: 120,825 characters / 4,885 lines
- Date: 2026-08-06
- Qualification: baseline only; not a cross-machine claim
- Limitations: TextKit layout, scroll frames, IME input, and live window frame time

See the HTML benchmark page for the current p50, p95, and target table.
