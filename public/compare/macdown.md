# Downright vs MacDown

Both are open-source Mac Markdown projects. MacDown is a compact editor and preview pair. Downright adds a native adaptive document surface, system integration, and word-level review of external agent changes.

Choose the tool whose editing model matches your work.

Reviewed/tested August 16, 2026. Primary reference: the [MacDown repository](https://github.com/MacDownApp/macdown). Verify current release behavior with the linked project before making a final switch.
