# Downright vs Marked

Marked is a dedicated Markdown preview companion. Downright combines preview, editing, source inspection, and external-change review in one native app.

Choose Marked when you already have an editor and want a specialist preview. Choose Downright when the file itself needs to be read, edited, and reviewed.

Reviewed/tested August 16, 2026. Primary reference: [Marked's official site](https://marked2app.com/). Features and pricing can change; use the official site as the current source.
