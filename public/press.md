# Downright press and product facts

Downright is a free, open-source native Markdown editor and viewer for macOS. It renders local Markdown exactly, reviews external agent rewrites live, and keeps the source file in charge.

- Platform: macOS 14+
- License: MIT
- Architecture: AppKit and TextKit 2; no WebView
- Integrations: Finder, Quick Look, Spotlight, Services, App Intents, and `down`
- Privacy: no account or telemetry required during ordinary use
